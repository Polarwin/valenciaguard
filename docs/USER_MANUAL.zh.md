# ValenciaGuard 用户手册（简体中文版）

> 适用于三种角色：**超级管理员**（物业公司负责人）、**员工**（物业管理员）、**业主**。
> 系统地址：https://valenciaguard.duckdns.org/

---

## 一、通用操作（所有角色）

### 登录
1. 打开 https://valenciaguard.duckdns.org/ ，自动跳转到登录页。
2. 输入用户名和密码（由超级管理员或员工发给您）。
3. 忘记密码？请联系管理员重置 —— 重置后新密码只显示一次，请妥善保存。

### 切换语言
页面右上角（登录页在底部）可随时切换：**ES（西班牙语）| EN（英语）| 中文**。
系统会记住您的选择。

### 安装到手机（像普通 App 一样使用）
- **安卓（Chrome）**：打开网站 → 右上角菜单（三个点） → “添加到主屏幕”。
- **iPhone（Safari）**：打开网站 → 分享按钮 → “添加到主屏幕”。

安装后桌面会出现蓝底 VG 图标，点开即是独立全屏应用，无浏览器地址栏。

## 二、超级管理员（物业公司负责人）

您拥有员工的全部功能（见第三节），外加**员工账号管理**：

### 创建员工账号
1. 进入 **Usuarios（用户）** 页面。
2. 在“添加用户”表单中：填用户名、角色选 **admin**、设置初始密码（可点“生成”自动产生强密码）。
3. 把用户名和初始密码告知员工，并提醒其尽快修改。

### 重置 / 删除账号
- 在用户列表每行可直接重置任何人的密码（新密码只显示一次）。
- 可删除员工账号和业主账号；**不能删除自己**，因此系统中永远至少有一名超级管理员（您）。

> 注意：只有您能创建、重置、删除 **admin（员工）** 账号；员工无权管理其他员工。

## 三、员工（物业管理员 / admin）

登录后进入管理后台，顶部导航包含：

| 功能 | 用途 |
|---|---|
| **Dashboard（仪表盘）** | 房产数量、入住率、本月/本年收款、逾期租金、待办提醒、未结工单 |
| **Properties（房产）** | 新增/编辑/删除房产；在房产详情页管理租客、合同、租金记录、文件、维修工单 |
| **Calendar（日历）** | 合同到期、通知截止日、涨租日、保险到期、收租日等关键日期一览 |
| **Owners（业主）** | 业主资料管理（姓名、邮箱、电话、微信、备注） |
| **Usuarios（用户）** | 为**业主**创建登录账号（角色选 owner，并可关联到业主资料）；重置业主密码 |
| **Rent calculator（涨租计算器）** | 按 IRAV 指数计算法定最高涨租额 |
| **AI assistant（AI 助手）** | 用西语/中文提问：LAU 租法问题、起草给租客的信件、翻译报价单等 |
| **Settings（设置）** | 公司名、通知邮箱、费用审批阈值、IRAV 比率；操作审计日志 |

### 日常工作流举例
1. **新业主入驻**：Owners 添加业主资料 → Usuarios 创建 owner 账号并关联 → 把账号发给业主。
2. **新房产**：Properties → 新增 → 填写地址、业主、状态 → 在详情页添加租客与合同（合同日期会自动计算：强制期、通知截止日、下次涨租日）。
3. **登记租金**：房产详情页添加每月租金记录，收到款后标记为已付。
4. **处理维修工单**：租客报修后创建 issue，AI 会自动给出紧急程度、责任方（房东/租客）建议和给租客的西语回复草稿；超过费用阈值的工单需业主批准。
5. **上传文件**：合同、押金单、保险单等上传到房产的 Documents，系统会尝试自动提取合同关键信息。

## 四、业主（Owner）

业主登录后进入**业主门户**（界面默认为中文，可切换）：

### 首页
- 房产数量、本月应收租金、入住率、未结工单 四张概览卡片。
- “我的房产”列表，点 **Ver detalles（查看详情）** 进入单套房产。

### 房产详情页
- **合同状态**：合同类型、起始日期、月租金、关键日期倒计时（到期 / 逾期天数）。
- **租金记录**：每月应付、实付、状态（已付 / 待付 / 逾期）。
- **工单**：该房产的报修及处理进度。
- **文件**：合同、保险等文件，可直接下载。
- **月度报告**：点击 **“Descargar informe del mes (PDF)（下载本月报告 PDF）”**，生成该房产的中文月报，方便转发或存档。

### 业主不能做什么
业主只能**查看**自己名下的房产、租金、工单和文件；不能修改数据，也看不到其他业主的信息。如需变更（如报修、提供新合同），请联系物业公司员工。

## 五、安全提示

- 初始密码（如 admin123）请在首次使用后尽快请管理员重置。
- 不要与他人共用账号；每位员工、每位业主应有独立账号，便于审计追溯。
- 密码至少 8 位；建议使用页面上的“生成”按钮产生随机密码。
